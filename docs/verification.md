# 중간고사 구현물 검증 — 가상 데이터 전용

기준일: 2026-11-02. 모든 미리보기는 읽기 전용이며 Slack 발송·고객 연락·실제 `data/` 변경을 하지 않았습니다. 근거는 `demo/answer_key.csv`, `demo/extracted/`, `demo/expected_ledger.csv`, `demo/expected_items.csv`입니다. 화면용 요약은 `reports/verification.html`, 엑셀 대조용 원 단위 합계는 `reports/monthly_totals.csv`(UTF-8 BOM, 쉼표 없는 숫자)입니다.

## ① 추출 정확도

- 목표: PDF 102개와 추출 JSON 102개를 정답표 102행에 빠짐없이 대응시키고, 문서 종류와 발주서 양식별 필드 일치율을 확인합니다.

## ② 알림 정확도 · dry-run

- 목표: `2026-11-02`의 진행중 건만 경과일로 분류하고, 주간 표시 대상과 새로 발송할 알림을 혼동하지 않습니다. 수주완·매출완·실주 상태는 대상에서 제외합니다.
- 방법: 가상 대장 40행 중 진행중 8행의 `기준일 - 견적일`을 독립 계산하여 30일 미만/30~60일/61일 이상으로 분류했습니다. 실제 주간 보고(`briefing.py`)와 비교했습니다. 이어 원본의 이미 처리한 플래그를 보존한 preview와, 진행중 8행의 발송 플래그만 **임시 복사본에서** 초기화한 preview를 `alerts.py`로 비교했습니다. `--apply`는 사용하지 않았습니다.

- 미발송 상태를 재현한 임시 복사본의 실제 dry-run: 확인필요 2건·실주 질문 4건; 독립 경과일 정답과 집합 비교해 누락 0건·오알림 0건. 원본과 임시 CSV 모두 바이트 변경 0건.
- 경계 테스트(`tests/test_alerts.py::test_november_second_29_30_60_61_day_preview_and_status_exclusions`): 29일=주간 알림 없음, 30일=주간 확인필요, 60일=확인필요, 61일=실주대상; 완료·실주 상태 각 1건씩 제외. **일일 새 알림**은 30일 당일에는 생성되지 않고 31일째부터 생성되며, 61일째는 확인필요를 중복 생성하지 않고 실주 질문만 생성됩니다. `--cover`를 이용한 30일 보고 기록은 별도 규칙입니다.
- 근거 명령: `python scripts/briefing.py --mode weekly --ledger demo/expected_ledger.csv --as-of 2026-11-02`; `python scripts/alerts.py --ledger demo/expected_ledger.csv --as-of 2026-11-02`; `python -m unittest discover -s tests -p test_alerts.py` (임시 CSV의 플래그 초기화·preview·바이트 불변·경계 검사 포함).
