# DemoLedgerKR-Regular.ttf

Source: [Google Fonts Noto Sans KR](https://github.com/google/fonts/tree/main/ofl/notosanskr), `NotoSansKR[wght].ttf` (copyright Adobe). Licensed under the [SIL Open Font License 1.1](OFL.txt).

For readable printed demo PDFs, its variable `wght` axis was fixed at 400 with FontTools and the font family/PostScript/variation prefix names were changed to `DemoLedgerKR` / `DemoLedgerKR-Regular` to avoid the reserved font name. The transformed TTF is also distributed under OFL 1.1. Source template PDF/images are *not* embedded in generated files.
